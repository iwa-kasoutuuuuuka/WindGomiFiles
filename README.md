<h1 align="center">WinGomiExplorer</h1>

<p align="center">
  <strong>Windows 11 向け 容量順ソート対応・タブ型ファイルエクスプローラー ＆ 大容量ゴミファイル抽出スキャナー</strong>
</p>

`WinGomiExplorer` は、Windows 標準のファイルエクスプローラーでは手が届かない**「フォルダごとの容量表示・サイズ順ソート」「拡張子・隠しファイル・システムファイルの常時全表示」「Cドライブ枯渇時の大容量・ゴミファイル高速抽出＆完全削除」**を1つに統合した、C# / .NET 10 (WPF) 製のネイティブデスクトップアプリケーションです。

---

## ✨ 主な特徴

### 1. 📊 フォルダ容量の非同期高速計算 ＆ 容量順ソート
* 従来のファイルエクスプローラーでは空欄だった**「フォルダのサイズ」**を、バックグラウンド並列処理（`FileSystemEnumerable` + `Parallel.ForEachAsync`）で高速に自動集計します。
* フォルダとファイルを合わせた**「容量の大きい順（降順）」ソート**に標準対応し、視覚的な**容量占有バー**でどのフォルダ・ファイルがディスクを圧迫しているか一目で把握できます。
* 「フォルダを上部にまとめる」チェックを外せば、フォルダとファイルを区別せず純粋なバイト数ランキング順に並べることも可能です。

### 2. 👁️ 拡張子・隠しファイル(H)・システムファイル(S) を標準で全表示
* ファイル名から拡張子を隠さず常時表示し、専用の「拡張子」カラムでもソート可能です。
* `AttributesToSkip = 0` により、隠し属性 `[隠し(H)]`・システム属性 `[システム(S)]`・読み取り専用 `[読取専用(R)]`・シンボリックリンク/ジャンクション `[リンク(L)]` をすべて可視化します。

### 3. 🔍 大容量・ゴミファイル抽出スキャン機能
* Cドライブや任意のフォルダをワンクリックでフルスキャンし、容量を圧迫している原因を瞬時に特定します。
* **3つの表示モードを 0秒（再スキャン不要）で切り替え可能**:
  1. **📄 巨大ファイル Topランキング**: 指定サイズ以上の巨大ファイルを大きい順に一覧表示。
  2. **📁 巨大フォルダ Topランキング**: 肥大化しているディレクトリを大きい順に一覧表示。
  3. **🧹 ゴミ・一時ファイル・キャッシュ候補のみ**: `Temp`、ブラウザ/GPUキャッシュ、`CrashDumps`、開発キャッシュ（`node_modules`, `nuget`, `pip`, `cargo` 等）、放置されたインストーラー等を自動判定して抽出。
* **最小サイズしきい値フィルタ**: `10 MB+` / `50 MB+` / `100 MB+ (推奨)` / `500 MB+` / `1 GB+` をリアルタイムに切り替えられます。

### 4. 📌 隠し「ゴミ溜まりスポット」直通サイドバー
* 普段 Windows 標準エクスプローラーでは隠しフォルダになっていて辿り着きにくい以下の肥大化スポットへ、左サイドバーからワンクリックで移動・スキャンできます。
  * `AppData\Local` / `AppData\Roaming` / `AppData\LocalLow`
  * `ユーザー Temp (%TEMP%)` / `Windows Temp (C:\Windows\Temp)`
  * `CrashDumps (クラッシュダンプ)`
  * `DirectX ShaderCache (GPUキャッシュ)`
  * `WinUpdate キャッシュ (SoftwareDistribution\Download)`

### 5. 🛡️ システム保護ロック ＆ 耐障害性「完全削除」エンジン
* **OS破壊を防ぐセーフガード**: `C:\Windows\System32`、`WinSxS`、`pagefile.sys`、`hiberfil.sys` 等のシステム重要領域は `🛡️ システム保護` として自動ロックされ、誤削除を防止します（`C:\Windows\Temp` 等の安全な一時領域は削除許可）。
* **空き容量を即座に回復する完全削除**: 確認ダイアログで削除対象リストと**解放予定の合計容量**（親子重複選択時の二重計上を自動排除）を確認した上で、ゴミ箱を経由せず直接完全削除します。
* **ロック中ファイルへの耐障害性**: フォルダ内に一部使用中のファイルがあっても処理が中断せず、読み取り専用・隠し属性を自動解除しながら削除可能なすべてのファイルを最後まで削除して空き容量を最大化します。

## ⌨️ キーボードショートカット & マウス操作

| 操作 | ショートカット / アクション |
| :--- | :--- |
| **新しいフォルダタブを開く** | `Ctrl + T` または `＋ 新規フォルダタブ` ボタン |
| **現在のタブを閉じる** | `Ctrl + W` またはタブの `✕` ボタン |
| **戻る / 進む / 上の階層へ** | `Alt + ←` / `Alt + →` / `Alt + ↑` |
| **最新の情報に更新・容量再計算** | `F5` または `🔄 容量再計算` ボタン |
| **選択項目を完全削除** | `Delete` または `🔥 選択項目を完全削除して容量を空ける` ボタン |
| **フォルダ移動 / ファイルを開く** | 行をダブルクリック（スキャンタブでは新しいタブでその場所を開きます） |
| **コンテキストメニュー** | 行を右クリック（新しいタブで開く / スキャン / パスをコピー / 標準エクスプローラーで開く / 完全削除） |

## 🚀 ビルドと実行方法

### 必要環境
* Windows 11 (または Windows 10)
* .NET 10.0 SDK (`net10.0-windows`)

### コマンドラインからのビルド・起動

```powershell
# リリースビルド
dotnet build -c Release

# アプリケーションの起動
Start-Process ".\bin\Release\net10.0-windows\WinGomiExplorer.exe"

# または dotnet run で直接実行
dotnet run -c Release
```
